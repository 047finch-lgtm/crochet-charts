# 撤销/重做用命令模式，不用快照

编辑器核心的所有修改都必须封装为命令（`Command.apply/revert`），撤销栈存命令序列而非状态快照。SRS 要求"50 步混合操作后撤销/重做两态与记录完全一致"，只有命令回放能精确保证；快照（含 immer 时间旅行）在 200×200 网格上限下内存浪费且两态一致只能近似成立。

## Considered Options

- **状态快照 / immer 时间旅行**：实现省事，但每步克隆全图；深操作（行列位移）的逆操作仍要做，等于没省。
- **命令模式（选定）**：Stitch Works（QUndoStack）、sconcho 同款架构；代价是每个编辑路径都要写逆操作，由 core 单测兜底。

## Consequences

- 拖动绘制必须聚合成单命令（一次落笔 = 一步撤销），否则撤销栈被拖动事件淹没。
- 新增编辑操作时 `apply/revert` 成对提交是硬约束，进 code review 检查项。
