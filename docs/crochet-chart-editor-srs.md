# 毛线图谱编辑器 SRS V0

**状态**：V0，待评审。**范围**：一期（FSR 里程碑 M0–M4 全量）。需求条目带验收标准；事实依据与决策背景见 [FSR](crochet-chart-editor-fsr.md) 及其引用的调研文档，本文不复述。每条需求的**验收**全部通过才算该条实现完成。

## 1. 范围

**本期做**：往返矩形网格钩针图解的绘制、结构编辑、文件管理与导出（下文 FR1–FR8）。

**本期不做**（V1 待定项，见 §6）：环形圈钩、棒针、图片识别导入、重复折叠/实例化、油漆桶/吸管/区域选择、协作与云同步。

## 2. 用户与场景

唯一目标用户：业余钩针爱好者。三个主场景：

- **S1 从零画图**：按教程脑内图样，在网格上逐格画出符号图解。
- **S2 改图**：打开已有图谱，改花样、插行删列。
- **S3 出图分享**：导出图片发社交平台，或导出 PDF 打印。

场景是需求的验收语境：每条 FR 的验收标准从这三个场景能观察到的行为出发。

## 3. 功能需求

### FR1 画布与网格

- **FR1.1** 图谱由矩形网格构成，每格可容纳至多一个符号，格子随画布缩放保持比例，缩放不损失清晰度（矢量渲染）。
  - 验收：放大 8 倍观察，符号边缘无锯齿、无位图模糊。
- **FR1.2** 画布支持滚轮/触控板平移与缩放；提供"适应窗口"与"100% 视图"快捷操作。
  - 验收：100×200 网格在 1366×768 视口中可平移缩放至任意区域全览或全屏细看，操作不超过 2 次手势。
- **FR1.3** 行号显示于网格起始侧，可整体开关；行号在行列增删后自动重排，保持从 1 开始连续。
  - 验收：在任意位置插入/删除行后，行号无跳号、无重复。
- **FR1.4** 网格尺寸上限 200×200；新建图谱默认 30×30，行列数可在新建时设定。
  - 验收：新建对话框可设 1–200 间任意行列数；输入超界被拒绝并提示。

### FR2 绘制工具

- **FR2.1** 铅笔：单击在格内放置当前符号；按住拖动连续经过的格子依次放置。
  - 验收：快速斜向拖动经过的所有格子全部落笔（无跳格），每格内容与当前符号一致。
- **FR2.2** 橡皮：单击/拖动清空格子符号；清空后的格子回到空态（非白色填充）。
  - 验收：擦除后格子无残留图形或颜色。
- **FR2.3** 仅铅笔与橡皮两种绘制工具；当前工具与当前符号在界面上持续可见。
  - 验收：任意时刻界面明确显示当前工具与当前符号，无需打开菜单确认。

### FR3 符号与颜色

- **FR3.1** 内置符号库含约 30 个常用钩针符号（锁针、短针、中长针、长针、长长针、引拔、加减针、枣形、爆米花、交叉、环形起针等），覆盖 JIS 画法 + 中文缩写惯例，每个符号带中文名与美式/英式术语标注。
  - 验收：30 个符号全部可选可画；任一符号的图例信息含图形、中文名、US/UK 术语四项。
- **FR3.2** 符号与颜色分离：符号是单色描线图形，线条颜色与格子底色为两个独立属性，均可指定；默认白底黑线。
  - 验收：设定线条红、底色黄后绘制，图解呈红符号黄格；两者可独立改回默认。
- **FR3.3** 符号库数据结构预留自定义符号接口（符号即 SVG 图形 + 元数据），本期不提供自定义入口。
  - 验收：新增一个符号只需增加一条数据记录 + 一个 SVG 图形文件，不改动绘制逻辑代码。

### FR4 网格结构编辑

- **FR4.1** 在光标位置插入空行/空列，后续行列整体位移。
  - 验收：第 5 行插入新行后，原第 5 行及以后内容逐一下移一位，内容不变。
- **FR4.2** 删除光标所在行/列，后续行列整体前移；删除含符号的行列需二次确认。
  - 验收：删除空行无确认直接执行；删除非空行弹确认，取消则网格不变。
- **FR4.3** 所有编辑操作（绘制、擦除、行列增删、属性修改）进入统一撤销/重做栈。
  - 验收：执行任意 50 步混合操作后，连续撤销 50 步回到初始态，再重做 50 步回到终态，两态与记录完全一致。

### FR5 重复区标记

- **FR5.1** 可在网格上框选一个矩形区段作为重复区，以括号/边框视觉标记，附文字标注（如"重复 3 次"）；标记可移动、可删除。
  - 验收：标记不随网格内容绘制被覆盖或误删；删除标记不影响格内符号。
- **FR5.2** 重复区仅为视觉标记，不产生重复执行语义（改标记内内容不自动传播）。
  - 验收：标注"重复 3 次"的区段内改一格，图解其他位置无变化。

### FR6 图例

- **FR6.1** 图例自动生成：收集当前图谱使用中的全部符号，每项含符号图形、中文名、美式/英式术语；按针法从简到繁固定排序；图谱内容变化后图例同步更新。
  - 验收：删除图中某符号的最后一个实例，图例该项消失；新增符号则出现，且排序符合约定顺序。
- **FR6.2** 图例作为图谱的组成部分随导出一并输出（见 FR8），图解本体与图例不可分离导出（"图解必须自带 key"的行业规范）。
  - 验收：三种导出格式均含完整图例。

### FR7 文件管理与自动保存

- **FR7.1** 图谱为存储单位，改动即自动保存到 IndexedDB；保存失败时界面显式告警。
  - 验收：绘制后直接刷新/关闭浏览器再打开，图谱与最后编辑状态一致；模拟存储失败（配额耗尽）出现告警且不静默丢数据。
- **FR7.2** 图谱列表页：缩略图预览（由图谱渲染缩略 SVG）、名称、最近编辑时间按倒序排列；支持重命名、复制、删除（删除二次确认）。
  - 验收：10 张图谱的列表可凭缩略图区分；复制出的新图谱与原图谱内容一致且可独立编辑。
- **FR7.3** 工程文件导出/导入：单图谱 JSON 文件（含版本号字段），导入生成新图谱，不覆盖已有。
  - 验收：导出→删除→导入，图谱内容逐格一致；导入未来版本格式（版本号高于当前）给出明确拒绝提示而非崩溃。

### FR8 导出

- **FR8.1** PNG：倍率选项 1x/2x/4x，默认 2x；导出范围为图谱 + 图例整体。
  - 验收：2x 导出 30×30 图谱宽度为 1x 的两倍且清晰；三种倍率均无裁切。
- **FR8.2** SVG：矢量导出，行号与标注保持为可编辑文本（不转轮廓）。
  - 验收：导出文件在 Inkscape/Illustrator 中可单独选中并修改文字。
- **FR8.3** PDF：A4 纵向打印排版——页眉图名、图谱、图例、页脚页码；走浏览器打印管线（"另存为 PDF"）；承诺 A4 可打印，不承诺像素级一致。
  - 验收：Chrome 与 Safari 各导出一次，A4 打印预览中图谱完整、图例齐全、无内容溢出页面。

## 4. 数据实体与约束

| 实体     | 字段                                                               | 约束                              |
| -------- | ------------------------------------------------------------------ | --------------------------------- |
| 图谱     | id、名称、行列数、创建/修改时间、工程格式版本号                    | 行列数 ∈ [1,200]；名称非空        |
| 格子     | symbolId（可空=空态）、线条色、底色                                | 每格至多一个符号；空态 ≠ 白色填充 |
| 符号     | symbolId、SVG 图形、中文名、us 术语、uk 术语、针法序（图例排序键） | symbolId 唯一；针法序全序         |
| 重复标记 | 起止行列、标注文本                                                 | 矩形区段；仅视觉，无执行语义      |
| 行号     | （派生）                                                           | 不落存储，由行列位置派生；恒连续  |

**一致性不变式**（任何操作后必须成立）：行号连续无跳号；图例符号集 = 图谱中使用符号集；撤销/重做任意深度后上述两条仍成立。

## 5. 非功能需求

- **NFR1 语言**：UI 仅中文。
- **NFR2 兼容**：Chrome / Safari 最新两个大版本为验收浏览器。
- **NFR3 性能**：100×100 网格下绘制、擦除、行列增删均无感知延迟（交互响应 < 100ms）。
- **NFR4 可靠**：自动保存后，浏览器崩溃/刷新不丢数据（以 FR7.1 验收为准）。
- **NFR5 零依赖**：无账号、无后端、无网络请求（PWA 离线可用；字体等静态资源随应用分发）。
